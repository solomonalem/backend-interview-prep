# Backend Interview Prep

Self-quiz study guide: **266 questions** across **19 sections**, weighted for senior backend roles (Node, Express, MongoDB, microservices, REST, security, AWS, Docker/CI-CD, Spec-Kit/MCP, and more).

## Live site

https://solomonalem.github.io/backend-interview-prep/

## How to use

- Click any question to reveal the answer — built for self-quizzing, not passive reading
- Search filters across all 266 questions (or press `/` from anywhere)
- Three callout types in answers:
  - **Senior signal** — what separates a senior answer
  - **Trap** — the common wrong answer
  - **Your material** — where OFS work is the answer (~25 times)
- Prints cleanly with everything expanded

## Local preview

Open `index.html` in a browser, or:

```bash
npx serve .
```

## Deploy

Static GitHub Pages from the `main` branch root — no build step.
