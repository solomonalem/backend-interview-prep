# 09 — Project Structure

> Exact folder layout. Follow this strictly so Claude Code knows where everything lives.

---

## Root

```
assessiq/
├── apps/
│   ├── web/                  ← React frontend
│   └── api/                  ← Express backend + BullMQ workers
├── packages/
│   └── types/                ← Shared TypeScript types
├── docker-compose.yml        ← Local dev: postgres + redis
├── .env.example
├── .gitignore
├── package.json              ← Root workspace config
└── tsconfig.base.json        ← Shared TS config
```

## Key Conventions

1. **Route files** — only handle HTTP: parse request, call service, return response. No business logic.
2. **Service files** — all business logic. No Express types (req, res). Easily testable.
3. **Worker files** — only handle queue jobs. Call services for logic.
4. **API files** (frontend) — one file per resource. Each function maps to one API route.
5. **Hooks** — encapsulate stateful logic (timers, events). Pages are thin.
6. **Store** — only for active session state (timer, current question, pending events). Everything else from React Query or local state.
7. **Types package** — any type used in both frontend and backend goes here. No duplicating types.
